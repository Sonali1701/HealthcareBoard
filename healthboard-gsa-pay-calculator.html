🔑 GSA API Key Setup
The GSA Per Diem API is free but requires an API key to use. It takes under a minute to get one.
1
Go to api.data.gov/signup and register with your work email. Your key arrives instantly.
2
Copy the key from your confirmation email (format: DEMO_KEY for testing, real key for production).
3
Paste it below. Your backend should store it in an environment variable GSA_API_KEY — never expose in client-side code in production.
